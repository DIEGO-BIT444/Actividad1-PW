# API de Incidencias

API creada con Node.js y Express para registrar, consultar, actualizar y eliminar incidencias.

## Tecnologías utilizadas

- Node.js
- Express
- JavaScript
- JSON

## Estructura del proyecto

```text
src/
├── App.js
├── package.json
├── controllers/
│   └── incidenciasControllers.js
├── routes/
│   └── incidencias.js
└── utils/
    └── helpers.js

    Instalación
Primero, abre una terminal en la carpeta principal del proyecto:
npm install

Iniciar el servidor
Desde la carpeta principal del proyecto:
node App.js


También puedes entrar a la carpeta src y ejecutar:
cd src
node App.js

El servidor se ejecuta en:
http://localhost:3000
